# 🎮 LoL_Auto_Accept_Game

![Windows](https://img.shields.io/badge/OS-Windows-blue)
![Python](https://img.shields.io/badge/Python-3.9+-yellow)
![Status](https://img.shields.io/badge/Status-Active-success)

Лёгкое трей-приложение для автоматического принятия игры в League of Legends.
Работает в фоне, без окна: только иконка в системном трее и нативное меню.

---

## ✨ Возможности

- 🔍 **Автопоиск `lockfile`** клиента League of Legends:
  переменная окружения → реестр Windows → перебор всех дисков `A:`…`Z:`.
  Найденный путь кэшируется и пересканируется только при перезапуске клиента.
- ⚡ **Автоприём ReadyCheck** через локальный LCU API (`127.0.0.1:<port>`).
- 🎨 **Динамическая иконка в трее** — 4 состояния:
  - 🟢 зелёная — ждёт игру / клиент не запущен;
  - 🟡 жёлтая — игра найдена (`ReadyCheck`), accept отправлен;
  - 🔵 синяя — в игре / выбор чемпиона / реконнект;
  - 🔴 красная — автоприём выключен вручную.
- 🖱️ **Меню трея**:
  - «Выкл» / «Вкл» — переключение автоприёма (текст меняется динамически);
  - «Выход» — корректная остановка воркера.
- 👆 Клик по иконке **только открывает меню** — состояние не переключается случайно.
- 🛡️ Проверка единственного экземпляра (порт `127.0.0.1:51837`) — второй запуск
  показывает сообщение и завершается.
- 📝 Логи пишутся в `%TEMP%\lol_auto_accept_game.log`.

## 🚀 Установка

1. **Установите Python** (если еще не установлен). Скачать можно с официального сайта: 👉 **[python.org/downloads](https://www.python.org/downloads/)**
   > ⚠️ **Важно:** При установке обязательно поставьте галочку **"Add Python to PATH"**.

2. **Клонируйте репозиторий** или скачайте файлы:
   ```bash
   git clone https://github.com/ВАШ_НИК/LoL_Auto_Accept_Game.git
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите программу**:
   ```bash
   python lol_auto_accept_game.py
   ```

Чтобы не висело чёрное окно консоли — запускайте через `pythonw`:

```bash
pythonw lol_auto_accept_game.py
```

Или переименуйте файл в `lol_auto_accept_game.pyw` и запускайте двойным кликом.

## 🕹️ Использование

1. Запустите приложение — в трее появится **зелёная** иконка.
2. Запустите клиент League of Legends и встаньте в очередь.
3. Когда игра найдётся — иконка станет **жёлтой**, accept уйдёт автоматически,
   в лог запишется `✅ Игра принята!`.
4. Правый клик по иконке → **«Выход»** для завершения работы.

### ⚙️ Ручное переключение

Правый клик по иконке → пункт **«Выкл»** (когда автоприём включён) или
**«Вкл»** (когда выключен). При выключении иконка становится красной,
опрос клиента приостанавливается, но приложение продолжает работать.

## 🔍 Поиск `lockfile`

Порядок поиска:

1. `LOL_LOCKFILE_PATH` в переменных окружения — полный путь к `lockfile`.
2. Реестр Windows:
   - `HKLM\SOFTWARE\WOW6432Node\Riot Games, Inc.\League of Legends`
   - `HKLM\SOFTWARE\Riot Games, Inc.\League of Legends`
   - `HKCU\SOFTWARE\Riot Games, Inc.\League of Legends`
3. Все доступные диски: `A:\Riot Games\League of Legends\lockfile` …
   `Z:\Riot Games\League of Legends\lockfile`.

Если клиент установлен в нестандартное место — задайте `LOL_LOCKFILE_PATH`:

```powershell
setx LOL_LOCKFILE_PATH "D:\Games\LoL\lockfile"
```

*(после `setx` нужно перезапустить приложение; для текущей сессии — `$env:LOL_LOCKFILE_PATH="D:\Games\LoL\lockfile"`)*

## 🛠️ Как это работает

Приложение читает `lockfile` клиента LoL — это текстовый файл вида
`LeagueClient:<pid>:<port>:<password>:https`.
Из него берутся порт и пароль для локального HTTP(S) API (LCU).

Далее воркер в отдельном потоке раз в секунду опрашивает эндпоинт:

```http
GET https://127.0.0.1:<port>/lol-gameflow/v1/gameflow-phase
```

Как только фаза становится `ReadyCheck` — отправляется:

```http
POST https://127.0.0.1:<port>/lol-matchmaking/v1/ready-check/accept
```

TLS-сертификат клиента самоподписанный, поэтому `verify=False`
(предупреждение `urllib3` точечно отключено).

## ⚠️ Известные ограничения

- Только Windows (используется `winreg` для поиска пути к клиенту;
  на других ОС останется перебор дисков — фактически бесполезен).
- Меню трея рисует сама Windows — pystray не пробрасывает кастомный шрифт,
  поэтому «жирный» текст в меню недоступен.
- Если игра принята вручную, пока иконка жёлтая — ничего страшного,
  повторный `accept` клиент проигнорирует.
